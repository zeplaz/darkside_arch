# darkside_arch

Out-of-process Archipelago client for **Darksiders Warmastered** (`darksiders1.exe`, Steam x64). Reads and writes game RAM from outside; no DLL injection. Run everything from the repo root.

| Track | Who | Install | Run |
|-------|-----|---------|-----|
| Runtime / AP | Players | `pip install -r requirements.txt` | `python -m ds_client` |
| Mapping | Contributors | `pip install -r requirements-dev.txt` | `python -m tools` |

## Status

The AP client is written and tested. **A seed is not playable yet:** no RAM offsets are mapped (0 / 132 locations), so nothing is reported or applied. Mapping Crossroads is the next step. Per-requirement status: [ds_client/README.md](ds_client/README.md#checklist).

| I want to… | Command |
|------------|---------|
| Play: connect to AP and watch RAM | `python -m ds_client --connect HOST:PORT --slot NAME` |
| Map location offsets (browser) | `python -m tools dashboard` |
| See every mapper command | `python -m tools` |
| Run the tests | `python -m unittest discover -s tests` |
