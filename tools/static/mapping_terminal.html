    HOW THIS WORKS
    
      
    
    
    
    Workspace tabs: SAVE DIFF (chests), RAM DUMP (live flag, after identity), SAVES (encode UserId to saves/edited/, then INSTALL to Steam). This page never writes process memory and never connects to AP — the runtime is python -m ds_client --connect HOST:PORT --slot NAME.
    
    
    
      
    
        
    CAPTURE A CHEST
    
        
    Two in-game save slots. The chest is a Keen WorldObject (Triggered), same table as Destroyed breakables. Not a RAM 0→1.
    
        
      
          
    1. Save while closed. Open it. Save again in another slot.
      2. 
          
    2. Pick the AP name. Set the two slot numbers. DIFF SAVES.
      3. 
          
    3. SAVE IDENTITY. ds_client still skips it until a RAM offset exists.
      4. 
        
    
        
    CLI: python -m tools scan --sav FILE --slots 1 2 --item "NAME"
    
        
    Inspect: python -m tools save-brief --slot 1 FILE.sav. Encode/install: SAVES tab, or python -m tools save-patch --sav FILE --userid ID --out saves\edited\FILE.sav --install.
    
        
    SAVES TAB
    
        
    ENCODE writes saves/edited/ (autosave only). INSTALL copies that file into Steam remote\ and autocloud\save\. Type INSTALL to confirm. Refuses while the game is attached.
    
        
    STATUS BAR
    
        
      
          
    • GAME — attached, pid, module base (ASLR; never stored).
      • 
          
    • SERVER — this page's backend. Red = restart python -m tools dashboard.
      • 
          
    • CHECKS — locations with a real offset. 0 means a seed cannot report anything yet.
      • 
          
    • ITEMS — inventory / goal rows with a real offset.
      • 
          
    • AP — slot@uri from ap_config.json.
      • 
        
    
      
    
      
    
        
    FIX OR REMOVE A ROW
    
        
      
          
    • Wrong offset: capture the same location again — Save overwrites it.
      • 
          
    • Skip it: set "enabled": false in targets.json.
      • 
          
    • Drop it: delete the object. Don't keep offsets you no longer trust.
      • 
          
    • Labels must match Locations.py exactly. Refresh the list with python -m tools sync-world.
      • 
        
    
        
    ITEM WRITES
    
        
    Not chests. Pick the row, copy python -m tools scan --item "Progressive Chaoseater", type the HUD number, change it, type again. Levels cap 4. Unmapped items wait; they never block others.
